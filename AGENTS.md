# Salcos Armory – Arbeitsregeln

- Wenn eine Änderung fertig, geprüft und bereit für GitHub ist, nenne dem Nutzer ausdrücklich eine passende Commit-Nachricht.
- Formuliere die Commit-Nachricht kurz, eindeutig und passend zu den tatsächlich vorgenommenen Änderungen.
- Sage ebenfalls klar, wenn noch nicht auf GitHub hochgeladen werden sollte, etwa weil der Build oder eine notwendige Prüfung fehlschlägt.
